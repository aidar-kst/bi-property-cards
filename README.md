# Цифровые визитки BI Property

Статический сайт для GitHub Pages: страница сотрудника, файл контакта (.vcf) и QR-коды (PNG и SVG) создаются автоматически из файла `data/employees.json`.

Подробная пошаговая инструкция — в файле **ИНСТРУКЦИЯ.html** (или ИНСТРУКЦИЯ.md).

Структура:

- `data/employees.json` — список сотрудников (редактируется вручную)
- `data/site.json` — общие данные компании (сайт, адрес офиса)
- `assets/` — логотип, орнамент, шрифты Montserrat (лицензия OFL), стили
- `tools/build.py` — генератор страниц, vCard и QR
- `.github/workflows/deploy.yml` — автоматическая сборка и публикация на GitHub
