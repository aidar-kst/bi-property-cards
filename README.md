# Цифровые визитки BI Property

Сайт для GitHub Pages. Страницы сотрудников, файлы контактов (.vcf) и QR-коды создаются автоматически из файла `employees.json`. Общие данные компании — в `site.json`. Генератор — `build.py`. Автосборка — `.github/workflows/deploy.yml` (текст для вставки лежит в `workflow-deploy.yml.txt`). Инструкция: `INSTRUCTION.html`.
